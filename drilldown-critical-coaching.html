What "critical coaching" means for the manager

  1. These get coached first. Before any single-metric issue, sit down with each critical driver this week — they're your highest-leverage conversation.
  2. Name both problems in one conversation. Don't run a safety talk and a damages talk separately. The message is "you're below standard on more than one thing at once, and that has to change."
  3. Document it and set a clear bar. Specific expectations, a check-in date, and what happens if the numbers don't move — per Einstein's standard progression.
  4. Re-check next period. If a driver drops off this list, the coaching worked. If they're still here, escalate.

How the list is built: Compounding = a driver in the worst 25% of two or more of the four drill-downs. Damages = damage count per branch; driver-safety = offenders ≤69; estimate = 2+ material over-runs; OT = worst-25% by OT hours. Window = Aug 1–9, 2026 (damages/safety/estimate) and Aug 1–7 (OT).
