What “critical coaching” means for the manager

  1. These get coached first. Before any single-metric issue, sit down with each critical mover — they’re your highest-leverage conversation.
  2. Name both problems in one conversation. Don’t run a safety talk and a damages talk separately. The message is “you’re below standard on more than one thing at once, and that has to change.”
  3. Document it and set a clear bar. Specific expectations, a check-in date, and consequences — per Einstein’s standard progression.
  4. Re-check next period. If a mover drops off this list, the coaching worked. If they’re still here, escalate.

How the list is built: Compounding = a mover in the worst tier of two or more of the four drill-downs. Damages = 2+ distinct damaging moves; driver-safety = safety score ≤69; estimate = 3+ material over-runs (min 5 jobs); OT = 10+ OT hours in the week.
